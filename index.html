Case studies

Problem → what I did → result.

The 900% rate error

Problem: In the utility Sheet, 'Jhute for Boiler' was entered at 135 BDT instead of 13.5 — a 900% spread against other units.

What I did: The dashboard's cross-unit rate comparison flagged it as a possible data error instead of hiding it inside totals.

Result: The Sheet was corrected (all 19 AFL rows now 13.5) and the total cost came down by about ৳6.6 lakh, to ৳39,092,250.

The 0.5 machine

Problem: The machine total was 9,726.5, not a round number — 3 machine types are shared across lines as 0.5 + 0.5.

What I did: Instead of rounding to 9,726, the dashboard shows one decimal when a count is fractional, so it matches the Sheet exactly.

Result: Management now sees the exact figure the Sheet holds — no silent rounding gap.

About this dashboard

Built with HTML5, CSS3 and vanilla JavaScript (ES6+) — no frontend framework. Data lives in JSON files (data/) and your own entries in localStorage. Calendars: Gregorian dates are exact; the Bengali calendar follows the Bangladesh revised calendar rules (year starts 14 April); Hijri dates are calculated with the Umm al-Qura tabular calendar via the browser's Intl API and may differ by a day from local moon-sighting announcements — use the Hijri adjustment in Settings. Prophet stories paraphrase the cited Quranic passages; hadith references are omitted unless verified; the daily rotation is a reading schedule, not a historical anniversary claim.
